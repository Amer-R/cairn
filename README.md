# Cairn — Interactive User Guides

Two self-contained HTML guides for the [Cairn](https://github.com/Amer-R/cairn) context-first agentic workflow toolkit.

## Guides

| File | Audience | Description |
|------|----------|-------------|
| [cairn-getting-started.html](cairn-getting-started.html) | Beginners | Step-by-step install → validate → dry-run using the change-management example |
| [cairn-user-guide.html](cairn-user-guide.html) | All users | Full interactive reference covering Epics 1–6 with scenarios, diagrams, and CLI cheatsheet |

## Usage

Open either `.html` file directly in your browser — no server required.
